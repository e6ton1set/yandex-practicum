Данные проекты были выполнены в ходе обучения на платформе Яндекс.Практикум (АНО ДПО «Образовательные технологии Яндекса») по направлению "Инструменты для анализа данных" в течение 3/4Q 2024.

Наборы данных предоставлены дочерними компаниями бренда Яндекс и их партнёрами и защищены соответствующими законами: https://yandex.ru/legal/practicum_termsofuse/
